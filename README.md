# WaylaidFavorTooltip

World of Warcraft **Forever** addon that shows Merchant's Favor and the cheapest Auctionator fill cost on Waylaid / Sealed crate tooltips.

## Install

Copy this folder into:

`World of Warcraft/_forever_/Interface/AddOns/WaylaidFavorTooltip`

Or use the [wow-addons-forever](https://github.com/liamcooper/wow-addons-forever) sync scripts, which keep this repo in sync with that AddOns tree.

## Optional dependency

- [Auctionator](https://www.curseforge.com/wow/addons/auctionator) — for fill-cost pricing on tooltips
